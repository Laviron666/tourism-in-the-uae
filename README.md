# Tourism in the UAE

Учебный сайт на русском языке о развитии туризма в ОАЭ. Песочно-золотой дизайн, изображения из проекта, тест из 20 вопросов с подсказками, результатом и объяснениями, материалы исследования и анкета из 8 вопросов с выгрузкой ответов.

## Запуск

Нужен Node.js. Установка зависимостей не требуется.

```sh
npm run dev
```

Откройте http://localhost:3000. Можно также открыть `index.html` напрямую в браузере.

```sh
npm run check
```

## Публикация

Статический сайт готов для Vercel. Framework Preset: Other; Build Command: без команды; Output Directory: `.`. Конфигурация находится в `vercel.json`.

Ответы теста сохраняются локально в браузере. Анкета не отправляет данные на сервер. Первые 10 вопросов основаны на презентации, ещё 10 составлены по её материалам. Источники статистики и стратегии приведены на сайте.
