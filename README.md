# Tourism in the UAE

Учебный сайт на русском языке о развитии туризма в ОАЭ. Песочно-золотой дизайн, изображения из проекта, тест из 20 вопросов с подсказками, результатом и объяснениями, материалы исследования и анкета из 8 вопросов с выгрузкой ответов.

## Запуск

Нужен Node.js 22 или новее. Для серверной статистики используется приватное хранилище Vercel Blob. Подключите его к проекту Vercel и выполните `vercel env pull .env.local --yes`. Этот файл содержит секреты и не должен попадать в Git.

```sh
npm install
npm run dev
```

Откройте http://localhost:3000. При открытии `index.html` напрямую общая статистика недоступна.

```sh
npm run check
npm test
```

## Публикация

Статический сайт готов для Vercel. Framework Preset: Other; Build Command: без команды; Output Directory: `.`. Конфигурация находится в `vercel.json`.

Прогресс теста сохраняется локально в браузере. После завершения сервер проверяет ответы и сохраняет итоговый балл с анонимными идентификаторами браузера и попытки в приватное хранилище. Общая статистика показывает число участников (уникальных браузеров), прохождений, средний балл, распределение и последние 10 результатов. Имена и ответы на отдельные вопросы не сохраняются. Повторная отправка одной попытки не увеличивает счётчик. Старые результаты до добавления статистики не учитываются.

Локальная разработка и preview-деплои используют отдельный префикс хранилища, чтобы проверки не попадали в статистику опубликованного сайта.

Анкета не отправляет данные на сервер. Первые 10 вопросов основаны на презентации, ещё 10 составлены по её материалам. Источники статистики и стратегии приведены на сайте.
